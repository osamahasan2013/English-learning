# Word Garden — English for Kids (KG1–Grade 2)

A progressive web app that teaches children English reading step by step: letter sounds,
phonics, blending, sight words, vocabulary, spelling and sentences. Parents manage a family
account with separate profiles and progress for each child and see what is going well and
what to practise next. It works offline and syncs when back online.
